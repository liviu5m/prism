# Forge: LLM Fine-Tuning, Serving & Evaluation Platform Roadmap

## Phase 1: Data & Environment
1. Set up: `python -m venv .venv` and activate.
2. Deps: Install `torch`, `transformers`, `peft`, `trl`, `datasets`, `huggingface_hub`.
3. Task: Pick one small, clear job (e.g., "Summarize code into high-level intent" or "Translate informal bug reports into structured JSON").
4. Data: Create `dataset.jsonl`. 50 manual, high-quality examples. Quality > Quantity.
5. Script: Write a simple Python script to load this JSONL using the `datasets` library.

## Phase 2: Fine-Tuning
1. Trainer: Use `trl`'s `SFTTrainer`.
2. Loop: Code a minimal training loop.
3. Run: Train for 1 epoch on your 50 samples. Save the adapter (PEFT).
4. Eval: Create a list of 10 test prompts. Run them against the base model and your adapter.
5. Compare: Print both outputs side-by-side. If the adapter output is better, you win.

## Phase 3: Quantization & Serving
1. Quantize: Use `bitsandbytes` to load in 4-bit (QLoRA) to save memory.
2. vLLM: Set up `vLLM` locally.
3. Test: Point `vLLM` at your saved adapter. Run a completion query.

## Phase 4: Production Wrapper
1. FastAPI: Write a single-endpoint API: `POST /generate`.
2. Logic: API receives prompt, calls vLLM, returns text.
3. Scaling: Measure RPS (Requests Per Second). Add basic queueing.
